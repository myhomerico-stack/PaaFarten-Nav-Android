# På farten Nav

Android-app til Barbussen Fyn & Jyllands bus-tablets.

Version: **0.1.0**

Appen viser den eksisterende Navigator fra `https://minside.fynogjylland.dk/navigator/` og bruger Androids lokationstjeneste under aktiv brug.

## Build

GitHub Actions bygger debug-APK automatisk ved push til `main`. APK'en findes som workflow artifact **PaaFarten-Nav-APK**.
